# PDF 编辑 · 软件使用说明

## 简介

PDF 编辑是一款本地 PDF 处理工具，所有文件均在您的设备上处理，**不会上传到任何服务器**。

支持以下功能：

- **交叉合并** — 多份 PDF 逐页交替排列（A1, B1, C1, A2 …）
- **顺序合并** — 多份 PDF 按顺序首尾拼接（A 全部 + B 全部 + …）
- **B 反向交叉** — 第二份 PDF 页序反转后与其余文档交叉合并（A1, Bn, C1, A2 …）
- **页序编辑** — 单文件内调整页面顺序、删除或旋转页面

## 基本流程

1. 在首页选择需要的功能
2. 选择 PDF 文件（合并类功能至少 2 个文件）
3. 点击「继续 · 预览页序」进入编辑界面
4. 预览并调整页序后，点击「导出 PDF」保存结果

## 功能详解

### 交叉合并

适用于双语文档、问答对照等需要逐页交替排版的场景。

**示例：** 文档 A 有 3 页，文档 B 有 2 页，合并结果为 A1 → B1 → A2 → B2 → A3。

**操作步骤：**

1. 依次选择 PDF A、PDF B（可继续添加 C、D …）
2. 可通过拖拽左侧手柄调整各文档的先后顺序
3. 进入预览界面确认页序，必要时可手动微调
4. 导出文件，默认命名为 `原文件名-mixed.pdf`

### 顺序合并

适用于将多份独立 PDF 拼接成一份完整文档。

**示例：** A（5 页）+ B（3 页）+ C（2 页）= 共 10 页。

**操作步骤：**

1. 至少选择 2 个 PDF 文件
2. 拖拽调整文档顺序（先出现的文档页面前置）
3. 预览确认后导出，默认命名为 `原文件名-merged.pdf`

### B 反向交叉

适用于纠正双面扫描时第二份 PDF 页序颠倒的情况。

**示例：** 文档 A 正常，文档 B 页序为 B3, B2, B1（扫描顺序问题），合并时 B 会自动反转后再交叉排列。

**操作步骤：**

1. 至少选择 2 个 PDF，**第二份（PDF B）将被自动反转**
2. 其余文档按正常顺序参与交叉合并
3. 导出文件，默认命名为 `原文件名-reverse-mixed.pdf`

### 页序编辑

适用于单份 PDF 的页面整理。

**支持操作：**

| 操作 | 方法 |
|------|------|
| 选中页面 | 点击缩略图 |
| 调整顺序 | 长按拖拽缩略图 |
| 旋转页面 | 选中后点击底部「旋转 90°」按钮 |
| 删除页面 | 选中后点击底部「删除」按钮 |
| 放大预览 | 选中后点击「放大预览」按钮 |

导出文件默认命名为 `原文件名-edited.pdf`。

## 预览编辑界面

进入预览界面后，您会看到所有输出页面的缩略图网格：

- 顶部显示总页数及操作提示
- 不同来源的页面以颜色标签区分（多文件合并时）
- 底部工具栏显示当前选中页的信息及操作按钮
- 点击右上角或底部「导出 PDF」保存文件

## 隐私与安全

- 所有 PDF 读取、合并、导出均在本地完成
- 应用不收集、不上传任何文件内容
- 导出时由系统文件选择器指定保存位置

## 常见问题

**Q：合并功能最少需要几个文件？**  
A：交叉合并、顺序合并、B 反向交叉均至少需要 2 个 PDF 文件。

**Q：可以合并超过 2 个文件吗？**  
A：可以。交叉合并和顺序合并支持添加任意数量的 PDF（A、B、C …）。

**Q：导出后的文件在哪里？**  
A：导出时系统会弹出保存对话框，由您选择保存位置和文件名。保存成功后界面会提示完整路径。

**Q：支持哪些平台？**  
A：支持 macOS、Windows、Linux 及 Web 等平台（取决于构建目标）。

**Q：旋转页面是永久修改吗？**  
A：旋转仅应用于导出的新文件，不会修改原始 PDF。

**Q：页数不一致的文件能交叉合并吗？**  
A：可以。页数较少的文档用完后，其余文档的剩余页面会按规则继续排列。
